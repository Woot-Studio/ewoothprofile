# Ewooth Studio — Story v2

Scroll story for [Ewooth Studio](https://ewoot.my.id/), a web studio for UMKM. This is a fresh build from the Story v2 frames, not a port of the old site.

Desktop scenes pin and scrub with GSAP ScrollTrigger. Below 768px the same story is stacked and unpinned. If JavaScript does not run, the copy, prices, and links stay in the page.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:4317

## Build

```bash
npm run build
npm run preview
```
